# 工作台优化方案 · 今日总览层

> 定位：个人工作台，核心目标「提升做片决策效率」，当前痛点「信息太散、找不到重点」。
> 本次为第一步（小步改造）：只新增顶部「今日总览层」，不动现有 4 大板块与 11 张卡片。

---

## 一、问题诊断

- 工作台现有 4 个板块（内容生产 / 数据底座 / 周度复盘 / 合规台账）、11 张卡片，信息完整、自动化已跑通。
- 但所有卡片视觉权重相同，没有主次；关键数字（消耗、成交、ROI、拒审条数）被埋在卡片描述文字里。
- 本质：不缺数据、不缺自动化，缺的是「把已采集的数据变成一眼能看懂的决策信号」的展示层。

## 二、改造方向（整体，供后续参考）

- 目标结构：链接仓库 → 三层决策仪表盘。
  - 第一层：今日总览（一眼看懂今天）
  - 第二层：决策三入口（今天投什么 / 今天做什么 / 什么不能做）
  - 第三层：明细台账（按需下钻，折叠收纳）
- 本次仅落地「第一层」。

---

## 三、今日总览层 · 设计定稿

### 1. 布局

顶部横向 4 块状态卡片，一屏看完，无需滚动：

| 区块 | 核心数字 | 对比/告警 |
|---|---|---|
| ① 投放大盘 | 今日消耗 · 今日成交 · ROI | ROI 环比昨日 ±x |
| ② 素材信号 | 最高 ROI 素材 + 今日异动/掉量素材 | 异动标涨跌方向 |
| ③ 合规红线 | 待处理拒审 N 条 · 累计扣分 N 条 | ≥1 条变红提醒 |
| ④ 账户状态 | 当前账户（如 FS-4） | 最近换户日期（如有） |

### 2. 各区块明细

**① 投放大盘**（最左，最重要）
- 显示：今日消耗、今日成交、ROI
- 数据来源：直播间日报（T-1 主采 + T-2 回填）
- 对比：ROI 旁标注「环比昨日 ±x」
- 说明：需标注「数据截至 X 日」，避免误读为实时

**② 素材信号**（核心决策块）
- 显示：最高 ROI 素材（素材名 + ROI 值）、今日异动/掉量素材 N 条
- 数据来源：素材明细
- 价值：直接回答「今天投什么 / 该不该止损」

**③ 合规红线**（约束条件）
- 显示：待处理拒审 N 条、累计扣分 N 条
- 数据来源：卡审记录 / 扣分素材
- 告警：任一 ≥1 条 → 红色高亮提醒（「不能做」的边界）

**④ 账户状态**（运行前提）
- 显示：当前账户（如 FS-4）、最近换户日期（如有）
- 数据来源：账户变更
- 说明：最简单但关键，账户错了全白搭

### 3. 关键规则

1. **数据时效标注**：所有数字标注「数据截至时间」，避免把 T-1 数据误当实时。
2. **告警阈值**：
   - 拒审 / 扣分 ≥1 条 → 红色提醒。
   - ROI 环比显著下降 → 醒目标示（语义为「恶化提醒」）。
3. **刷新方式**：定时刷新，跟随 09:00 主采节奏（非实时打接口）。
4. **颜色语义**：采用「恶化标红」的告警语义，非涨跌红绿惯例。

## 四、数据来源与接口映射

| 投放大盘 | 直播间日报 | 消耗 / 成交 / ROI | 每天 09:00 |
